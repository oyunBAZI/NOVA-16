## Interfaces and reproducible verification

New native executable: n16c. Project orchestration: Python3.10+ scripts/n16.py.
Compiler API: compile, owned Result/deinit, writeDebugMap; map schema3 adds scoped
frame/global variables without changing legacy or assembly schema2 output.
Checked machine interfaces add validateRom/validateState/replaceCpu/resetChecked;
snapshot.encodeChecked validates serialization. Public mutable internals remain
for source compatibility and forensic use; callers should use checked interfaces.
Guest ABI/library contracts are docs/guest-abi.md and guest/README.md.

Local final suite:94 unit/integration tests; four isolated arithmetic model tests.
Source compiler positives execute ordinary V1 ROMs; the oracle is test-only.

1402/19618 feedback PCs (not line coverage). Final CI preserves its independent

Actual SDL2 events/controls/scaling/all-pixel readback pass locally using the

Native ReleaseSafe baseline-CPU packages include four tools, all ROMs/maps,

rebuilds and runs original/typed projects with extracted tools, without Zig/SDL.

provenance before publication; it is not OS executable signing or notarization.

## Performance and practical limits

Clean same-host three-sample ReleaseSafe measurement: CPU39.38ns/instruction,
headless0.791ms/frame,4,097-symbol assembly3.998ms, Crates/Studio compile6.350/
7.257ms, application frames0.949/0.927ms, snapshot encode/restore176.45/163.33µs.
Full history1.707µs/step, max32 exact states2,101,248bytes. Candidate capture50.34ns
is only a lower bound, not a delivered delta implementation. Expanded benchmark
RSS57,704KiB includes two16MiB compiler arenas. Raw samples and comparison limits
are in docs/benchmarks/v0.4-linux.json and docs/performance.md; no speedup claimed.

Language revision1 deliberately excludes heap, floats, strings, aggregate values
as parameters/results and multi-file typed compilation. It has1MiB source,
32768tokens,8192ASTnodes, depth64,16MiB private compiler capacity,128 functions,
128word local frames/64 active frames and unchanged8KiB ROM. All guest library
code is linked currently; Crates payload7944 bytes leaves little code capacity.
Studio payload5010 bytes. Input remains hardware bit-latched; full puzzle redraws
consume several logical frames. Crates detects simple corner deadlocks, not all
unsolvable layouts. Studio persists through snapshots and exports its framebuffer
through debugger/SDL; it has no host filesystem device.

No known failing V1 correctness gate is accepted for release. RC scope does not
claim production stability, arbitrary-input mathematical compiler completeness,
or universal performance. Follow-up V2 implementation is separately scoped:
approve revision2 → explicit profile dispatch/isolation → headless audio/MMIO/WAV
→ timer/IRQ/IRET/snapshot/reverse → optional SDL queue. Current shipped hardware
remains V1; the isolated mixer is not an audio device.

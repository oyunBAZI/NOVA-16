## Phase 0 — passed

original/developer/game/stress/security acceptance returned 0. ReleaseSafe baseline
CPU stripped build, 72/72 Safe tests, all three CLI acceptance suites and actual
SDL pixel/input/resize tests returned 0. Guided Safe fuzz completed 10,289 runs,
146 unique, no failure (seed 0x4e313603). Compatibility fixtures are recorded in
reliability/v0.4-baseline.json; original framebuffer and snapshot vectors pass.

Before implementation, the reported defect was reproduced on unmodified v0.3:
a real debugger snapshot was patched to active PC C000, its payload CRC recomputed,
and `loadsnap`/`regs` accepted it as `PC=c000 ready`, no error. Reproduction output
is preserved in the working verification checkpoint; Phase 1 will add the failing
regression before changing validation.

## Phase 1 — passed locally
The new active-C000 regression failed against v0.3 (expected SnapshotState,
found success), then passed after adding persistent-state validation to restore.
Added Machine validateRom/validateState/replaceCpu/resetChecked and snapshot
encodeChecked; debugger saves use the checked encoder. Candidate edits and
restores commit only after validation. A 12-PC × 8-stop-state matrix exercises
executable/denied/odd/trapped combinations. Added ROM length/padding and checked
reset/edit rejection tests. Stopped next-PCs and trapped fault PCs are preserved;
latched input/released keys, counter maximum/wrap remain legal. No guest timing,
ISA, N16S fields or valid golden serialization changed.

Linux/Zig 0.17.1: 74/74 tests, build, original and developer acceptance returned
0. The independent N16S golden and all original ROM hashes pass. Raw mutable
host structs remain source-compatible; checked methods are the supported path.

## Phase 2 — passed locally

## Phase 3 — passed locally
Added ABI1 guest arithmetic (bounded unsigned/signed division/remainder,
comparisons, checked add/sub/multiply/conversions), checked memory/arrays,
packed-pixel/clipped rectangle/opaque bitmap-sprite/font/numeric/palette graphics,
latched input/releases, frame waits, counters and caller-owned deterministic PRNG.
Every routine's arguments, results, clobbers, scratch and limits are listed in
guest/README.md. Generic font code adapts the original Breakout design without
changing its original source or behavior. Libraries execute only V1 instructions.

ROM tests execute independent wide signed/unsigned division oracles, boundaries,
ABI sentinels/stack, memory/array rejects, pixel nibbles/clipping, palette atomicity,
font/number/bitmap execution, input latches and PRNG/frame helpers. Linux/Zig0.17.1
80/80 tests, build and original CLI acceptance returned 0. Original golden hashes
unchanged. Library routines use bounded guest loops; no host drawing helpers.

## Phase 4 — passed locally
Implemented Zig n16c with bounded UTF-8 lexer, AST/parser, named types,
function/scoped-variable resolution, strict type/constant checks, direct V1
assembly lowering, ABI1 static/frame assignment, original source origins and
staged CLI output. u16/i16/bool, constants/globals/locals, casts, wrapping math,
bitwise/shifts/comparisons/short-circuit/ternary, branches/loops, nested/recursive
calls, fixed scalar arrays and scalar-field structs execute on the original CPU.
Dynamic bounds/divisor/frame failures are guest stores/BRK/HALT, not host VM code.
Limits include input/tokens/AST/depth/symbols/types, a private 16MiB owned arena,
static/local data and unchanged 8KiB ROM capacity. Aggregate by-value calls,
strings/heap/floats are explicitly outside language revision 1.

86/86 Linux Debug tests passed, including >=25 positive real-ROM cases and

source caps, deterministic compilation, and runtime failures. Compiler CLI
acceptance reassembled emitted ordinary assembly to identical bytes, booted the
